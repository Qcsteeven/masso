Ты проверяешь интерфейс МАССО. Приложение запущено (`make up`), адрес — `http://localhost` (если в запросе другой — используй его). Демо-учётки — в `backend/seed/` или `.env.example`.

Для каждого экрана из запроса:
1. Открой соответствующий макет `docs/mockups/<экран>.html` (file://) и сделай скриншот.
2. Войди под нужной ролью, открой экран приложения, сделай скриншот в `.artifacts/ui/<роль>-<экран>.png`.
3. Сравни: есть ли все ключевые блоки макета (заголовки, фильтры, таблицы, кнопки действий, сообщения состояния), русские тексты, цвета статусов.
4. Прочитай консоль браузера и неуспешные сетевые запросы.
5. Проверь основной сценарий экрана кликами (например, фильтр → таблица обновилась; «Запросить подсказку» → подсказка появилась).

Ответ — таблица: экран | чего не хватает по сравнению с макетом | ошибки консоли/сети | сценарий прошёл да/нет. Без советов по «улучшению дизайна» — только расхождения с макетом и ошибки.
