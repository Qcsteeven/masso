# Frontend

- Внешний вид — по `docs/mockups/*.png` и `docs/mockups/source/*.dc.html` (рис. 33–43 ТП ред. 2, Claude Design): переноси структуру, токены и цвета статусов из `docs/mockups/README.md`, не придумывай новый дизайн.
- Данные — только через TanStack Query и клиент `src/api`, который разворачивает конверт `{status, data|error}` и показывает `error.message` (на русском).
- Тексты интерфейса — на русском. Сообщения состояния обязательны для генерации, запуска среды, проверки, экспорта, переключения LLM (ТП разд. 10).
- Формы: подпись 30–35 % ширины, поле 65–70 %. Фильтры отчётов «Дата начала»/«Дата окончания» обязательны.
- Терминал — `@xterm/xterm` + `@xterm/addon-fit`, WebSocket открывается по токену из `POST /api/sessions/{id}/ws-token`.
- Всё основное доступно с клавиатуры; у кнопок-иконок есть `aria-label`.
