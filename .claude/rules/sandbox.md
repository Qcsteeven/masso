# Песочница и проверки — правила безопасности

- Флаги контейнера из спеки §7 обязательны все сразу; изменение любого — только с записью в `docs/DEVIATIONS.md` и тестом безопасности.
- Команды checks, fault- и fix-скрипты передаются через exec в момент выполнения; в образ их не класть, на диск песочницы не писать.
- Exec — от пользователя `student`, с таймаутом; вывод обрезать до разумного размера перед записью в БД.
- Каждый созданный контейнер помечен label `masso.session` и `masso.user`; удаление — `remove(force=True, v=True)`.
- Образ `webstack`: всё изменяемое — в `/srv`, порты > 1024, без sudo/su, без docker CLI.
