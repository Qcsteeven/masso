# МАССО — мультиагентная система ситуативного обучения

Учебный проект (ИРНИТУ, «Проектирование АСОИиУ»). Реализуем **первую очередь** (опытный образец) по ТЗ и ТП. Пользователь — Лев; общение на русском, кратко.

## Источники истины (в порядке приоритета)
1. `docs/02-mvp-spec.md` — что именно строим: данные, API, алгоритмы, безопасность. Читай нужный раздел перед любой фазой.
2. `docs/03-plan.md` — фазы и критерии «Готово, когда».
3. `docs/rev2/TZ.pdf`, `docs/rev2/TP.pdf` — ТЗ и ТП редакции 2 (уже описывают первую очередь), `docs/rev2/CHANGES.pdf` — что изменено. Исходная редакция 1 — `docs/source/` (только чтение). Диаграммы ТП — `docs/diagrams/*.drawio`.
4. `docs/HANDOFF.md` — что осталось и особенности облачного контейнера (Docker, зеркала, прокси).
5. `docs/mockups/` — макеты экранов из Claude Design (PNG + `source/*.dc.html`, токены в README), эталон внешнего вида.

Если требование неясно или спека противоречит ТЗ — спроси, а не угадывай. Если осознанно отходишь от ТЗ/ТП/спеки — **добавь строку в `docs/DEVIATIONS.md`** (дата, пункт документа, было, стало, почему). Это нужно для последующей правки ТЗ/ТП.

## Команды
- `make up` / `make down` / `make logs` — docker compose
- `make migrate`, `make seed` — Alembic и сид-данные
- `make check` — ruff + mypy + eslint + tsc + unit-тесты (back и front). **Запускай перед каждым коммитом.**
- `make test-integration` — тесты с реальным Docker (маркер `docker`), `make e2e` — сквозные
- `make sandbox-image` — собрать образ песочницы
- Backend: `cd backend && uv run pytest tests/unit -q`, `uv run ruff check --fix .`, `uv run mypy app`
- Frontend: `cd frontend && pnpm test`, `pnpm lint`, `pnpm typecheck`
- БД: `docker compose exec db psql -U masso masso`

## Архитектура (кратко, детали — спека §1)
- Модульный монолит FastAPI: пакеты `backend/app/<компонент>/` = компоненты C4 из ТП. Межмодульные вызовы — через сервисные классы, не HTTP.
- Хранилище одно: PostgreSQL + pgvector. **Не добавляй Neo4j, ChromaDB, Redis, Celery, Kubernetes** — это вторая очередь.
- Фоновые задачи — один asyncio-worker (`app/worker.py`), состояние только в БД.
- LLM — только через `app/llm_gateway` (OpenAI-совместимый клиент, fallback external → local → template). В тестах — `FakeLLM`, реальные вызовы в unit-тестах запрещены.
- LangGraph — только для графов ScenarioAgent и AssessmentAgent (спека §9).

## Правила кода
- Python 3.13, полная типизация, mypy strict для `app/`. Pydantic v2 для всех входов/выходов. SQLAlchemy 2 async.
- Все ответы API — единый конверт `{request_id, status, data|error}`, коды ошибок только из спеки §10, сообщения ошибок для пользователя — на русском.
- Код, идентификаторы, коммиты — на английском; UI-тексты, отчёты, подсказки студенту — на русском.
- Новая функциональность = тест в том же коммите. Алгоритмы (дефициты, балл, уровни) — unit-тесты на фикстурах.
- Миграции только через Alembic (`uv run alembic revision --autogenerate`), никогда не правь схему руками.
- Перед использованием API LangGraph, aiodocker, FastAPI, TanStack Query, xterm — сверься с актуальной документацией (Context7).

## Безопасность — IMPORTANT
- Студент никогда не получает `checks`, `faults`, `reference_fix`, `answer_key`, системные промпты, чужие данные. Для ответов студенту — только схемы `*Public`; на каждый такой эндпоинт — тест.
- Песочница: `user=student`, `cap_drop ALL`, `no-new-privileges`, `network_mode none`, read-only rootfs, лимиты CPU/RAM/pids. Никогда `privileged`, никогда проброс docker.sock внутрь песочницы.
- Секреты — только из env. Не читай и не печатай `.env`.

## Рабочий цикл фазы
1. Прочитай раздел фазы в `docs/03-plan.md` и связанные разделы спеки; посмотри `docs/DEVIATIONS.md`.
2. Покажи короткий план (файлы, шаги, проверки) и дождись «ок».
3. Реализуй небольшими шагами, после каждого — тесты.
4. `make check` (прогон удобно делегировать агенту `test-runner`), затем ревью диффа агентом `reviewer`.
5. Отметь чекбоксы «Готово, когда» в плане, коммит `phase-N: <что сделано>`.

При компактизации сохраняй: номер текущей фазы, список изменённых файлов, незакрытые чекбоксы, команды проверки.
