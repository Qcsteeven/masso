# Печатная компоновка диаграмм курсового проекта

В этой папке находятся 22 редактируемые диаграммы, использованные в актуальной пояснительной записке. Исходные модели сохранены в `docs/diagrams/`; эти файлы содержат их компоновку для печати на А4.

Сохранены идентификаторы всех элементов, подписи, типы фигур, источники и получатели связей. Изменены расположение и размеры элементов, ориентация дорожек процессов, переносы текста и шрифт. Дополнительные факты, сущности и связи не добавлялись. В компонентной модели сервера две ссылки на агентные графы приведены к номеру рисунка 33 в пояснительной записке.

Мягкие переносы и невидимые точки переноса служат только для разбиения длинных слов и идентификаторов. В пояснительной записке крупные модели продолжаются на нескольких страницах с перекрытием смежных областей. Расчётный размер надписей при печати — не менее 10,5 пт.

Результат сравнения моделей и число печатных фрагментов записаны в `model-preservation.json`.
