# Схемы с согласованными ссылками

Копии исходных схем для текущей нумерации рисунков пояснительной записки. После добавления пяти иллюстраций аналогов обновлены внутренние номера рисунков. В схеме проверки удалена ссылка на отдельную схему кодового задания, которая не входит в эту пояснительную записку; само действие сохранено. Геометрия, элементы, связи и печатные размеры схем сохранены. Изменения подписей перечислены в `reference-edits.json`. Исходный технический проект не изменялся.
